# Impersonator

A RuneLite plugin that locally replaces the appearance of other players with configurable NPC appearances.

For a list of NPC IDs, visit https://oldschool.runescape.wiki/w/NPC_IDs

## Features

- Adds an **Impersonate** submenu to other players' right-click menus.
- Provides three configurable NPC IDs.
- Provides a Reset option.
- Reapplies a selected appearance when RuneLite rebuilds a player's composition.
- Appearance changes are local to your RuneLite client.
- Selected appearances are persisted by player name.

## Configuration

Open **Impersonator** in RuneLite's plugin configuration panel and enter the NPC IDs you want to use.
